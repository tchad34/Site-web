V67 — Affiches automatiques pour À LA UNE

Lorsqu'un administrateur ajoute un film à À LA UNE, NoxAdmin demande automatiquement une affiche de film HD à la fonction nox-featured-poster. La fonction utilise TMDB et choisit une affiche de film, au format original.

Configuration requise côté Supabase Edge Function :
- Secret TMDB_API_TOKEN = API Read Access Token TMDB.

Dune — Partie Deux conserve l'image R2 personnalisée déjà configurée.

Aucune validation d'image n'est demandée à l'administrateur : l'affiche est associée automatiquement au moment de l'ajout.
