NOXSTREAM — VERSION FICHE COMME CAPTURE

Cette version reprend la fiche film du modal de l'accueil telle qu'elle apparaît dans la capture de référence Joker : Folie à Deux (version V49).

Conservé :
- fiche #detailModal de l'accueil ;
- affiche compacte sur mobile ;
- FICHE FILM, titre, métadonnées et synopsis ;
- Bande Annonce, Ma liste et Favori ;
- bloc LECTEUR ;
- Version française / Version originale et boutons lecteurs ;
- catalogue complet des 4 624 films ;
- dossier Films/ avec F majuscule ;
- chargement des images du catalogue depuis images-films/images-films-XXX.json vers les URLs R2.

La fiche HTML individuelle conserve également le chargeur R2 par chunks testé dans la version FICHE_R2_V2.
